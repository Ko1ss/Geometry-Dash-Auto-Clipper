# Changelog

## v1.0.0
- Initial release of **GD Auto Clipper**!
- Added OBS WebSocket v5 integration with auto-reconnect.
- Added automatic detection and capture for:
  - Level completions (100%)
  - New Personal Bests from 0%
  - StartPos personal records and configurable minimum gain runs
  - Configurable minimum floor threshold
- Added post-death reaction padding (3.5s+) to capture voice and death animations.
- Added Continuous Session and Replay Buffer capture modes.
- Added in-game notifications when clips are saved.
